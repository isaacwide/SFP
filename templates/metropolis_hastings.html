Algoritmo Metropolis-Hastings

Selecciona el tipo de implementación

El algoritmo Metropolis-Hastings es un método MCMC (Markov Chain Monte Carlo) que permite generar muestras de distribuciones de probabilidad complejas mediante una cadena de Markov. Elige entre el caso continuo o discreto según tu necesidad.

📊

Caso Continuo

Implementación del algoritmo M-H para distribuciones continuas. Ideal para muestrear de distribuciones normales, exponenciales, uniformes y gamma cuando el muestreo directo es difícil o imposible.

4 Distribuciones
∞ Rango
Normal • Exponencial • Uniforme • Gamma
🎯

Caso Discreto

Implementación del algoritmo M-H para distribuciones discretas usando cadenas de Markov con matriz de transición simétrica. Perfecto para muestrear de distribuciones con estados finitos.

3 Distribuciones
N Estados finitos
Poisson • Uniforme • Geométrica
